# Upload instructions

1. Download and extract the final ZIP.
2. Open your existing Credit Card Fraud Detection repository in GitHub Desktop.
3. Copy the **contents** of this folder into the repository root; do not upload the ZIP as a single file.
4. Preserve the existing Git commit history and review changes before committing.
5. Keep `creditcard.csv` out of the public repository; download it separately from Kaggle.
6. Verify the README, dashboard and notebooks are visible in GitHub.
7. Commit with a descriptive message such as `Add validated fraud models, updated Excel dashboard and technical report`.
